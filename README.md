## 🏦 Group Project: Unified Banking Database System

**Members:** Camacho, Rene R. | Celindro, Aaron Creed P. | Naig, Ariane Mae A. | Umbao, Pauleen Therese H.

A database design project proposing a unified banking system that handles customer information, accounts, transactions, loans, and audit logging.

**Key highlights:**
- 5 normalized entities: `Customer`, `Account`, `Transaction`, `Loans`, `Audit Log`
- Proper PK/FK relationships with documented cardinalities
- ERD designed using crow's foot notation
- SQL implementation: DDL (table creation) + DML (inserts, SELECT queries)

**Concepts applied:** Entity-Relationship Modeling, Normalization, Foreign Key Constraints, SQL DDL/DML
